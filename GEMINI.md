# Project Rules & Skills Configuration

## Design & Frontend Skills Integration

When designing, building, or modifying any UI, layout, styling, copywriting, or frontend code in this project, you MUST actively apply the following installed skills:

### 1. design-taste-frontend
- **Path**: `.agents/skills/design-taste-frontend/SKILL.md`
- **Purpose**: Prevent generic AI UI templates and low-agency design patterns.
- **Directives**:
  - Always read the brief and infer the appropriate design language before coding.
  - Ban AI-slop tropes: generic purple gradients, centered dark mesh heroes, generic glassmorphism, uncalibrated animations, generic Inter + slate-900 typography.
  - Respect project style: Light mode only, `#F4F6F8` background, Tailwind CSS v4, Plus Jakarta Sans font, crisp elevated card drop shadows (`shadow-sm`), and clear information hierarchy.
